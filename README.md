# Grabify - Video & Audio Downloader

Download videos or extract audio from YouTube, Instagram, Facebook, TikTok, and more.

## Run Locally

```bash
pip install -r requirements.txt
python app.py
```

For the desktop app (PyQt5 wrapper):

```bash
pip install -r requirements.txt
python main.py
```
